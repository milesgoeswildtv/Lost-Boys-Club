# Native App Settings — Afterdark Brotherhood

This file is the source manifest for the Chaturbate App V2 **Advanced Settings** editor.

## Install the graphical settings panel

1. Open the Afterdark Brotherhood app in the Chaturbate Developer Portal.
2. Open its **Advanced Settings** configuration editor.
3. Replace the existing settings schema with the complete contents of `chaturbate/advanced_settings.json`.
4. Save the app configuration. Open the app's settings from the room's Apps interface to see the native grouped controls.

GitHub does not synchronize this manifest into the Developer Portal. Saving this file in the repository does not, by itself, change the live app's settings UI.

## Controls currently wired to code

- **Welcome new viewers** — gates the existing entry greeting.
- **Tip acknowledgment notices** — silences only the automatic thank-you message; tip totals, room-goal progress, and permanent VIP tracking remain active.
- **Enable loyalty points** — master switch for loyalty earning.
- **Daily visit points** — points once per UTC day; zero disables this earning source.
- **Viewing points per 5 minutes** — points per completed viewing interval; zero disables this earning source.
- **Meaningful chat points** — points per qualifying message; zero disables this earning source.
- **Meaningful chat cooldown** — minutes between eligible chat awards.
- **Show informational tip menu**, **heading**, and **footer** — changes the public `!tipmenu` / `!menu` display without changing saved menu entries.
- **Announcement interval** — controls the cadence for the existing rotating announcement scheduler (5–1,440 minutes); announcements remain off until enabled through the existing owner control.
- **Enable free giveaways** — gates viewer status and entry commands while preserving any active giveaway and entries; broadcaster controls remain available.
- **Enable viewer queue** and **maximum waitlist size** — gates viewer queue interactions and caps queue capacity without deleting stored queue entries or bookings.
- **Room goal defaults** — default timer for newly created goals, default 25/50/75% milestone announcements (100% is always retained), and initial carryover/repeat preferences.
- **Broadcast panel layout** — choose the existing goal-focused layout or the game-and-record layout.
- **Game availability** — independently enable/disable viewer participation in Codebreaker, Word Scramble, Dirty Would You Rather, Position Impossible, and Dirty Charades. Broadcaster controls remain available when a game is disabled.

All fields have safe defaults matching the current behavior. Existing points, reward catalogues, pending redemptions, VIP totals, goals, and other persistent KV data are not reset by changing these settings.

## Deliberate boundary

The native settings form is generated by Chaturbate from this schema; it is not a custom embedded web page. This settings pass exposes only controls wired to existing behavior. Goal milestone, carryover, and repeat fields supply defaults when a goal record does not already contain an explicit broadcaster choice; the goal commands remain authoritative once those values have been saved. Goal stages, tip-menu rows, reward catalogue entries, giveaway state, and queue contents remain persistent operational data managed by their existing subsystem commands; they are not duplicated into settings fields. Lowering the queue cap does not erase stored entries. Disabling giveaways or the viewer queue gates public interactions but preserves the saved state.
